TALES OF VANITY — LOGIN POR @USERNAME

1. Publique os arquivos deste ZIP no GitHub Pages normalmente.
2. No Supabase, crie/deploy uma Edge Function com o nome EXATO:
   login-with-username
3. Substitua todo o código dela pelo conteúdo de:
   supabase/functions/login-with-username/index.ts
4. Em "Verify JWT with legacy secret", deixe DESATIVADO, pois o usuário ainda não está logado quando chama essa função.
5. Não é necessário SQL adicional para esta alteração.
6. Não altere nem compartilhe SUPABASE_SERVICE_ROLE_KEY. Ela já é disponibilizada pelo ambiente da Edge Function.

Resultado:
- @username + senha funciona.
- username sem @ + senha também funciona.
- e-mail + senha continua funcionando.
- o e-mail associado ao username não é enviado ao navegador.
